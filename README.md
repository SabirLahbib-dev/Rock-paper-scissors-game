# Rock Paper Scissors Game

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features

- Play against the computer
- Track score across rounds
- Reset score history
- Toggle auto-play mode
- Keyboard support for quick gameplay
- Score saved in browser localStorage

## Project Structure

- `rock-paper-scissors.html` — main page structure
- `styles.css` — styling for the game UI
- `scripts.js` — game logic and score handling
- `images/` — emoji assets for rock, paper, and scissors

## How to Run

1. Open `rock-paper-scissors.html` in your browser.
2. Click one of the move buttons to play.
3. The computer will choose a random move and the result will be displayed.

## Controls

- Click the rock, paper, or scissors buttons
- Press `R`, `P`, or `S` on the keyboard
- Press `A` to start or stop auto-play
- Press `Backspace` to reset the score with confirmation
